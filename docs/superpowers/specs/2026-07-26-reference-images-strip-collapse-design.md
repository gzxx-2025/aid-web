# 编辑弹窗参考图条折叠展示设计

> 日期：2026-07-26  
> 状态：已确认并实现（用户要求直接落地）  
> 规范：`docs/2026-07-22-frontend-development-standards.md`、`docs/2026-07-22-existing-code-safe-remediation.md`

---

## 1. 问题与目标

### 1.1 现象

编辑弹窗右侧「生成」区，文本域上方的「导入参考图」缩略图条在数量变多时会占满纵向空间，挤压提示词区域，阅读与操作成本上升。

### 1.2 目标

1. **超过 4 张时默认折叠**：只展示前 4 张缩略图，并显示下拉箭头  
2. **行内展开**：点击箭头展示全部；再次点击收起  
3. **覆盖所有带该条的编辑弹窗**：场景图、分镜图（对话作图）、分镜视频（图生/多参）  
4. **不改业务上限**：各弹窗现有上传/导入数量上限与接口参数保持不变，仅改展示

### 1.3 非目标

- 提高或取消参考图上传上限  
- 改为浮层/下拉菜单式展开  
- 改 SSE、生成接口、提示词 `@图片` / `@音频` 解析逻辑  
- 顺手大重构巨石弹窗文件

---

## 2. 范围

| 接入点 | 文件 | 现状 |
|--------|------|------|
| 场景图 · 生成 Tab | `EditSceneImageModal.vue` | 内联 `generate-source-images-strip`，上限 4 |
| 场景图 / 分镜图 · 对话作图 | `DialogueDrawPanel.vue` | 共享条，上限由 `maxSourceCount` 控制（场景 4 / 分镜 1） |
| 分镜视频 · 图生/宫格 & 多参 | `StoryboardGeneratePanel.vue` | `i2v-reference-strip`；图生上限 1，多参可更多 |

说明：分镜图「生成」若仅 1 张参考图上限，折叠逻辑不会触发，但仍统一走共享组件，避免分叉。

---

## 3. 交互契约

| 条件 | 展示 |
|------|------|
| `count ≤ 4` | 全部缩略图；无箭头 |
| `count > 4` 且收起 | 同一 flex 流：前 4 张 →「导入参考图」→ 下拉箭头 |
| `count > 4` 且展开 | 同一 flex 流：前 4 张 →「导入参考图」→ 第 5 张起卡片 → 向上箭头（箭头跟在列表末尾，无分层区块） |

附加规则：

1. 展开态删除后若 `count ≤ 4`：自动收起并隐藏箭头  
2. 切换 Tab / 关闭弹窗 / 组件卸载：重置为收起  
3. 「+ 导入」按钮是否显示仍由各调用方 `maxCount` / 现有条件决定，本组件不改上限语义  
4. 预览、删除、点击缩略图的事件语义与接入前一致

折叠阈值常量：`COLLAPSE_VISIBLE_COUNT = 4`（仅 UI，与业务 `maxSourceCount` 无关）。

## 4. 实现方案

### 4.1 抽共享组件（方案 A）

新建：`components/steps/GenerateSourceImagesStrip.vue`

职责：

- 接收参考图列表（至少含 `url` / 可选 `thumbnail` / `title` / `name` / `id`）  
- 管理本地 `expanded` 状态  
- 按契约裁剪可见列表并渲染箭头  
- 通过 emit 抛出：`remove`、`preview`（可选）、`open-adder`  
- 支持 slot 或 props 控制「+」文案与是否显示

样式：

- 优先复用现有 `generate-source-images-*` / `i2v-reference-*` 视觉（尺寸、圆角、删除钮）  
- 差异收敛到组件内；调用方 scoped 只留必要外壳间距  
- 箭头使用 Ant Design Icons（如 `DownOutlined` / `UpOutlined`），风格对齐创作弹窗深色条

### 4.2 接入方式

1. `DialogueDrawPanel`：替换内联条 → 使用共享组件  
2. `EditSceneImageModal` 生成 Tab：替换内联条 → 使用共享组件  
3. `StoryboardGeneratePanel` 的 `i2v-reference-strip`（`storyboardVideo` + `imageToVideo`）：替换为共享组件或薄封装（同一折叠内核）

### 4.3 行为冻结

- 不改 `generateSourceImages` / `referenceImages` / 多参分桶的写入与校验  
- 不改「最多 N 张」的 warning / slice  
- 不改导入弹窗与 resolve 流程

## 5. 验收清单

- [ ] 场景图生成：≤4 张无箭头；若业务侧将来 >4（或测试注入）则折叠/展开正常

- [ ] 分镜图对话作图：上限 1，表现与现网一致（无箭头）

- [ ] 分镜视频图生：上限 1，表现与现网一致  
- [ ] 展开后删除至 ≤4：箭头消失、自动收起  
- [ ] 切 Tab / 关弹窗再开：为收起态  
- [ ] 删除、预览、「+」导入行为与改前一致  
- [ ] 视觉：深色条、缩略图尺寸、删除钮与现网接近（视觉等价）

## 6. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 多参条与场景条样式不完全一致 | 组件接受 `variant`（如 `scene` / `i2v`）或 class，保持视觉等价 |
| 巨石文件 diff 噪音 | 只替换参考图条片段，禁止顺手格式化 |
| 误改上限 | 验收明确：上限逻辑零改动 |

回滚：删除共享组件引用，恢复三处内联模板即可。
