# 剧集流程：隐藏项目配置步骤 + 分集页入口

日期：2026-07-16  
状态：已批准（方案 1），直接开发

## 目标

1. 剧集进入某集创作后，顶部步骤条**完全隐藏「项目配置」**，只显示后 6 步，从「剧本创作」起算。
2. 进集时不经过 `/create/global-setting`，直接落到剧本创作（或「生成剧集」目标步）；服务端步骤 1 用 `stepInitAdvance` 对齐。
3. 分集列表「新增一集」旁增加「项目配置」按钮，打开与首页同形态的配置弹窗；**作品类型禁用**。
4. 打开前校验：项目下**任意一集**已有分镜脚本 → 不打开弹窗，tooltip：「该剧集已经生成分镜脚本，请删除后重新修改项目配置」。

## 实现要点

- 展示层过滤 `global-setting`；后端仍为 7 步，点击/状态用真实 step index。
- 复用 `CreateFirstStepModal`（`flowEditMode`）+ `useCreateFlowGlobalSettingModal`。
- 校验：对各集并行 `userStoryboardList`，任一条目非空即拦截。

## 非目标

- 不改后端步骤枚举；电影流程不变；上传剧本页不变。
